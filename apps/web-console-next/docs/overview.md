# web-console-next

Next.js 15 + opennextjs/cloudflare delivery of the ambient web console (per-environment, Workers + Static Assets)

The ambient console UI — Next.js compiled to a Cloudflare Worker with
Static Assets, configured against the API edge. Public at
`https://ambient-web-console-next-{stage,prod}.rahulvarghesepullely.workers.dev`.

## Depends on

- **api-edge** — Cloudflare Worker for the API edge Runtime
