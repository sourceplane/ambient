# sdk

Runtime-agnostic TypeScript SDK for the ambient control plane API

A shared package of the ambient workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the ambient control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the ambient web console (per-environment, Workers + Static Assets)
